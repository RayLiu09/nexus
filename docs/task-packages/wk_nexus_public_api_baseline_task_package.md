# nexus-public-api 全资产类别性能基线任务包

日期：2026-11-19。执行方式：单 Agent，仅只读实测与分析。

## 目标与约束

基于当前资产中心分类及公开资源发现接口，为每类资产定义 5 个不同维度的问题，实际使用 `nexus-public-api` skill 的路由、参数校验与 HTTP 执行器获取答案，形成问题集、逐题答复、调用性能基线及优化建议。遵循 ARCHITECT.md 的业务 API 边界、SPEC.md 的溯源要求、WORKFLOWS.md 的验证证据约定以及 skill 的只读、证据和统计口径。

## 范围

- 核对当前公开资产类别、数量、检索能力及已部署服务版本的可确认信息。
- 每类 5 题：基础查找、条件过滤、事实/内容提取、汇总比较、综合分析；根据该类别能力选择专用结构化查询或文档证据路径。
- 顺序执行，记录 skill HTTP 耗时、完整工具链耗时、响应字节、状态、trace_id、返回规模、空结果与证据可用性；至少三轮重复，明确预热及分位数的样本限制。
- 区分 skill 工具数据获取耗时与 Agent 组织答案耗时，不将手工组织答案伪称为自动问答端到端计时。
- 可在 `/tmp` 创建临时测试驱动、受限短期响应文件；仓库只新增本任务文档、测试集、脱敏指标和结果报告。

## 排除与禁止

不修改业务代码、skill、依赖、数据库结构/数据、运行服务或配置；不部署、不执行迁移、不写入/导入资产，不做高并发压测。不输出凭据、L3/L4 明文或完整文档，不把第一页当全量统计；无专用聚合的类别只做有边界样本比较，并明确限制。保留其他工作区修改。

## 交付与验收

- 当前分类清单、每类 5 题的机器可读测试集及逐题有来源的简要答复。
- 可复用的参数/调用链记录、脱敏逐次测量与汇总统计；原始正文不入库。
- 性能分析区分数据缺口、结果语义、工具编排和服务端热点，建议标注实测依据、优先级、收益假设及后续验证方法。
- 公开 API 实测、结果范围/引用抽查和 `git diff --check` 证据；当前报告不构成代码或性能改动的 Review Gate 放行。

## 实测口径补充

当前源码资产中心可见18类，公开发现与skill覆盖17类；新增电商示范基地未进入公开工具。交付共90题：`testset.json`固定85道可测题，`coverage-gap-testset.json`保留基地类5题及缺口。85题各三轮；另外顺序复测热点、输出投影、故障恢复和精确标签，补充结果与主测试分开统计。测试驱动及本地配置映射仅位于`/tmp`；仓库仅新增文档与脱敏测试产物，没有修改skill或业务代码。公开只读接口仍按原机制写入查询审计。

## 完成与核验

交付入口：[分析报告](../review/nexus_public_api_asset_baseline_2026-11-19.md)、[90题逐题答复](../testing/nexus-public-api-baseline-20261119/questions-and-answers.md)、[产物与复现说明](../testing/nexus-public-api-baseline-20261119/README.md)。主测试429次均200，热点补测另有2次503、10次500及10次传输失败，均已保留，未据主测试宣称整体稳定。
