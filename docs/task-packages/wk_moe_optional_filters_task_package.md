# Task Package: 教育部字典修复与同步范围选填

日期：2026-10-26。状态：实现、验证及本地 API 重启完成。单 Agent 顺序实施。

## 目标与契约

- 排查 API 数据同步“数据源字典不可用”的真实原因，修复实际拉取请求兼容性；按用户后续指令将已核验的年份/省份字典硬编码到前端，计划表单不再请求动态字典。
- 教育部计划年份默认当前年份；省份、专业名称、专业代码可省略或清空，非空仍按官方编码/格式校验。年份仍必填，创建时默认当前年，已保存计划编辑保持原年份；按用户补充要求允许 2013–2035，2036 及以上拒绝。
- 省份为空表示所有省份，专业条件为空表示该条件不限制。拉取仅携带非空条件；写入必须从每行返回的省份、专业字段确定领域事实，保留非空查询范围校验及跨计划幂等去重。
- 读官方接口仅作有界诊断，不自动创建计划或批量执行同步。与既有数据同步认证、分页完整性、审计、直入库、无 AI 治理契约保持一致。

官方字典有界实测；创建/编辑默认值与选填提交；前端固定字典且无字典请求；API 查询校验；无省份/无专业的混合返回行入库、来源范围校验、重复跳过；已有专业布点和数据同步回归；Console 类型检查。API Contract、Permission/Audit、Frontend UX、领域数据对照证据归档，用户已授权修复并在现有本地服务验证。
