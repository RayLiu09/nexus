# Task Package: 岗位职业能力分析 SKILL 的 OpenAPI 与数据缺口分析

日期：2026-10-26。单 Agent 顺序分析。

依据：用户指定 `docs/e2e/occupational-competency-analysis/SKILL.md` 及同目录 reference/生成器契约；`docs/generated/public-function-tools`；ARCHITECT、SPEC、WORKFLOWS。

目标：在“职业证书依赖联网搜索，其余依赖由 NEXUS 资产平台提供”的新来源边界下，分析完成技能 JSON/双模式离线 HTML 等输出所需能力及欠缺。

补充约束：用户明确专业教学标准读取不以 `active` 为前提；现有接口的 active 筛选属于待调整的行为，不能当作目标设计条件。SKILL 生成新的 PGSD 文件，不依赖既有 PGSD 分析数据；旧能力项、旧图谱与 KSA 转换只可作为可选复用说明，不计入必要依赖或阻塞缺口。

权威性边界：用户明确 NEXUS 平台内容默认具有权威性，不要求额外验证发布机构、发布日期、版本等结构化元数据。缺少这些字段或官方来源链接不计为数据缺口；仅检查实际采用的正文能否读取、与任务是否相关、引用能否正确表达。平台外职业证书仍依 SKILL 核对证书性质及岗位适用性。

工具边界：忽略 SKILL 中具体检索工具函数名称，所有数据检索使用 NEXUS 生成的公开工具集；职业证书也通过该工具集的联网搜索接口取得。按实际行为评估能力，不因缺少旧工具同名函数判定缺口。

范围：完整读取技能与校验契约；对照 55 个生成工具、实际公开路由与 DTO；必要时对开发库进行只读计数/字段覆盖抽样；输出分层矩阵、可复用能力、确证缺口、数据与映射限制、优先级及验收建议，形成 `docs/occupational_competency_skill_openapi_data_gap_analysis_2026-10-26.md`。

禁止：不执行岗位研究、不付费联网搜索、不编造岗位结论；不修改技能、业务代码、权限、AI 配置或数据库；不新建标准事实、正式职业分析成果或部署服务；不把设计建议视为已批准实施。不将 HTML/Excel/PDF 本地渲染误计为平台数据接口缺失。

验收：逐项覆盖 reference JSON 字段、证据/检索状态、PGSD/KSA 映射、相关岗位、职业/专业代码/版本/层次核验、输出导出要求；区分已有接口、参数增强、数据补录、Agent 适配及真正新 API；说明只读数据覆盖的时间点与局限，保留可核查文件定位。
