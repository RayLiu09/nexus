# 文档资产视图自定义检索任务包

> 专业简介和人才需求调研的最新字段范围及五个专业视图的布局调整，以后续 `wk_major_document_search_refinement_task_package.md` 为准。本任务包保留初版范围作为验证追溯。

- 来源：用户要求产业政策、产业报告、行业报告等列表右上部支持区域、行业、内容标签检索；Prototype v2.2 的资产中心文档列表；ARCHITECT.md 的 normalized_ref 正式治理标签及服务边界；WORKFLOWS.md 的 API/UX Review Gate。
- 目标：六类通用文档列表（产教政策、产业报告、行业报告、专业简介、人才需求调研、教学案例）提供统一检索；已有领域投影列表维持专用检索。
- 范围：内部文档列表 API 的可选 region/industry/content_tag 参数、Console 页面参数和共用检索组件、针对筛选与分页的测试、合同与评审证据。单 Agent 顺序实施。
- 合同：每项为最长128字符的自由文本，去除两端空白；区域和行业分别对选中 ref 的对应类型正式标签作不区分大小写的字面包含匹配；内容标签匹配非区域/行业的正式标签，缺少这类索引时回退最新正式 governance_result.tags，与列表展示一致。三项取 AND，分页前过滤并计算完整 total。主题按钮数量同步纳入三项条件；换页保留条件；检索/重置/主题切换返回第一页；重置三项条件保留主题和每页条数。专业简介额外保留资产名称筛选。
- 交互：列表工具栏右侧，宽屏横向排列，小屏自动换行；有检索、重置及明确输入标签，Enter 提交，URL 可刷新还原。
- 排除：数据库迁移、标签/治理状态变更、公开API改动、语义检索或标签推荐、构建图谱、修复此前OpenAPI测试的其他问题、服务长期启动、提交/推送。
- 禁止：页面内只筛当前页、用原始AI输出代替正式标签、查询非当前目录选中ref、逐行查库、改变版本状态/可见性/权限、改无关样例文件。
- 交付：共用组件及六类接入、后端筛选、定向前后端测试、typecheck/lint、API/Frontend UX Gate 证据；不将实现自检标记为人工验收。
- 验收：独立/组合/空结果/字面通配符/历史ref隔离/正式标签回退/服务端分页计数通过；客户端换页保留、提交重置页码、主题计数与查询口径一致；原有预览下载和编辑流程不受影响。
