# 专业资产视图检索调整任务包

- 来源：用户在本地验证后指定各专业资产列表的检索字段及右侧布局。
- 目标：专业简介仅按专业名称、专业代码、院校名称检索；人才需求调研按上述三项及内容标签检索；专业教学标准、标准课程库、人才培养方案保留现有条件，统一列表顶部右侧布局，按钮统一“检索”。各视图只保留一个检索表单。
- 合同：新增内部文档列表 `major_name`、`major_code`、`institution_name` 可选关键词，每项最长128字符，去空白后字面包含匹配、不区分大小写；组合条件取 AND，在 COUNT/分页之前执行。匹配目录选中 ref 的列表实际显示字段，包括人工修订优先级和人工清空值。人才需求调研的 content_tag 沿用正式标签合同。UI 不传入专业简介不再需要的 q/region/industry/content_tag，人才需求调研不传入 region/industry；内部旧可选参数保留兼容。
- 交互：右侧单一“检索/重置”，回车提交；检索/重置回到第一页、保留每页条数，翻页保留条件，URL 刷新恢复。窄屏换行。标准课程库保留 libraryId 范围。
- 范围：两类文档内部列表与共用 SQL 谓词、五个 Console 列表及服务端参数、必要测试及文档。单 Agent 顺序实施。
- 禁止：仅过滤当前页、改变显示字段来源/人工修订合同、修改公开 API、迁移/数据回填、权限/状态/治理写入、改动无关样例文件。
- 验证：组合条件、人工修订/清空及源字段回退、当前 ref 隔离、计数分页、输入长度；前端字段范围/唯一表单/参数传递及已有预览编辑回归；typecheck、可执行的 lint、实际 PostgreSQL 只读查询。相关服务继续用于用户验证，API 若需重启保持 Worker 关闭。
- Review Gate：提供 API Contract / Frontend UX 自检证据，合并前人工评审，不自动标记人工验收。
