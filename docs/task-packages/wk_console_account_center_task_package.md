# NEXUS Console 账户信息中心任务包

## 任务名称

NX-00A 生产级账户信息中心与修改密码界面

## 来源上下文

- `SPEC.md`：Console 使用本地身份认证，平台管理员和业务专家是 Console 角色。
- `ARCHITECT.md`：认证边界由服务端和现有会话机制负责，前端不得绕过权限。
- `WORKFLOWS.md`：P0 Console 交互需通过 Frontend UX Gate；身份相关界面需保持 Permission And Audit Gate 边界。

## 目标

优化 Console 顶部右侧登录信息中心，清晰呈现当前身份和账户操作，并提供仅用于演示的修改密码表单界面。

## 范围

- `nexus-console/components/Topbar.tsx` 与对应样式。
- Topbar 账户中心和修改密码组件测试。
- 移除 Topbar 环境标签及其展示逻辑。

## 范围外

- 不新增或修改修改密码 API、认证 API、Cookie、JWT 或后端数据模型。
- 不实现密码实际保存、密码找回、多因素认证或安全策略后端校验。
- 不开放新角色，不改变 `api_caller`、运维角色与 Console 的边界。

## 验收标准

- 顶部右侧不再显示 Demo、Staging、生产等环境标签。
- 账户入口显示头像、显示名和角色摘要，点击后展示身份、组织、会话状态、修改密码和退出登录。
- 修改密码表单包含当前密码、新密码、确认新密码，并具备前端必填、长度和一致性校验。
- 修改密码提交不发送网络请求，只显示接口尚未接入的明确提示。
- 桌面端和移动端菜单不溢出、不遮挡关键操作；退出登录仍调用既有会话登出逻辑。

## Review Gate

### Frontend UX Gate

- [ ] 账户信息和操作层级清晰，符合现有 Console 视觉系统。
- [ ] 修改密码表单错误态、提交提示和关闭行为可演示。

### Permission And Audit Gate

- [ ] 仅展示当前服务端会话返回的身份信息。
- [ ] 本次不新增 API、不提交密码、不改变权限和审计边界。
