## 验证结果

- Console 定向 Vitest：2 个测试文件、6 项测试通过。
- 离线样例只读检查：按钮顺序 `tree/sunburst/treemap/graph`；共享树有 33 个能力叶节点，P21/G3/S6/D3；1 个“未归类”岗位占位、3 个任务、10 个工作内容；导出的节点关系数据有 57 节点、56 条边。
- 用户补充后，实际数据库只读确认 14 份分析，并取得各自标准化记录与原始对象，14/14 原始 SHA-256 一致；canonical XLSX parser 解析后，109/109 源任务有描述与工作内容声明坐标。领域侧仅 107 个任务，发现一份历史数据少两个任务。
- 只有 2/14 明确提供岗位类表头；原表岗位称谓不能自动当作正式岗位类。发现多份跨任务或同任务能力重号，必须区分来源事实、重复及冲突。
- 只读诊断脚本已运行，结果写入 `docs/review/wk_occupational_ability_three_views_source_audit.json`；不记录原文全文、不写业务数据库。
- 本次没有运行浏览器或真实 API 联调；产品满足度依据当前工作区代码，实际源数据可提取性依据 14 份原始文件，不将离线样例当作业务资产。未实施模型变更或历史数据修复。
