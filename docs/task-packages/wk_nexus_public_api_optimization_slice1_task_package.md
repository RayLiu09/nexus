# nexus-public-api 优化单元1：作答输出与错误后连接恢复

日期：2026-11-19；单Agent顺序实施。输入为全资产90题基线及用户本轮实施授权。

## 冻结范围

- 用户要求：skill返回以模型分析/作答为目的，引用证据按需取；已知业务标签足以检索时优先明确type的精确标签；库内不足时可联网补充，答复清楚标识平台/网络来源。
- 在现有执行器增加`answer`本地投影，保留有效内容、事实、统计口径、来源类别和最小续查ID；省略完整metadata/lineage/locator等证据细节。`serve`默认answer，单次`call`默认full及显式旧模式保持兼容。
- 输出预算缩减必须标记截断、原始数量，尽可能保留可作答内容和续查ID；不得以摘要/截断结果作为全量分布。
- HTTP错误或连接明确关闭后释放连接，不自动重试、不隐藏500/503；下一请求建立新连接。该修复只处理可验证的客户端恢复，不宣称解决远端根因。
- 更新skill正文、流程、路由提示与必要项目文档。验证精确标签、缺口后联网及网络来源字段；不以字符串匹配替代真实行为验证。
