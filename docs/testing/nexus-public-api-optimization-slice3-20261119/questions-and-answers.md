## 完整性与性能口径

初验pageSize=200的115组在本地12K输出预算下保留100组并标明截断，见question-set-initial.json；最终改为每页50组，三页分别50/50/15组，均未截断、分组无重复且计数合计312。原始90题基线与其历史缺口文件不覆盖。

最终56次调用均200。每个重复请求顺序执行10次；发现、详情和续页各一次。耗时含本地HTTP与审计，不是远端PostgreSQL生产延迟，也不是模型作答耗时。详见question-set-results.json。
