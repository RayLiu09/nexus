# 职业教育专业课程与岗位数据资产平台项目立项文档

**项目名称**：职业教育专业课程与岗位数据资产平台建设项目  
**文档性质**：项目立项论证稿  
**编制日期**：2026-09-23  
**建设周期建议**：分阶段建设，首期形成可用闭环，后续持续扩充数据范围和业务应用

## 一、建设背景与目标

### 1.1 建设背景

职业教育专业建设正在从“依据经验设置课程”转向“依据产业、职业、岗位和能力要求持续优化”。这一转变要求学校和专业建设部门同时掌握两类基础事实：一是专业教学标准明确的培养目标、课程结构、典型工作任务和教学内容；二是企业真实招聘市场反映的岗位需求、工作任务和技能要求。只有将两类事实放在同一套可追溯的数据底座上，才能形成课程设置、岗位需求和人才培养质量之间的持续校准机制。

目前相关数据通常分散在专业教学标准、人才培养方案、岗位招聘网站、业务数据库和部门 Excel 文件中。文件格式不统一、命名口径不一致、岗位信息重复、课程抽取依赖人工，导致数据“能查不能比、能看不能算、能用不能追溯”。业务人员往往需要反复整理材料，才能回答“某专业应该开设哪些课程”“市场岗位需要哪些核心任务和技能”“现有课程与岗位需求是否匹配”等问题。

NEXUS 已具备企业数据留存、标准化治理、业务分析和应用服务能力。本项目在现有平台基础上，聚焦专业教学标准课程库、市场岗位需求归一化和业务面数据资产视图三个建设方向，形成从标准课程基线到市场岗位事实、再到业务分析应用的闭环。

### 1.2 总体目标

项目总体目标是建设一套“标准可引用、岗位可归一、数据可分析、结果可追溯”的职业教育数据资产能力：

1. **构建标准课程库**：从专业教学标准中提取专业身份、职业面向、培养目标、课程类型、典型工作任务、教学内容与要求以及知识/技能/工具/素养标签，形成版本化、证据绑定的标准课程库，为专业建设和课程体系对标提供统一基线。
2. **形成市场岗位画像**：接入爬虫引擎同步的 JSON 岗位数据，保留原始岗位观测，完成清洗、岗位需求身份识别、六要素任务抽取、岗位任务画像和岗位核心技能画像，并在完整数据集范围内归一为标准岗位库。
3. **建设业务面数据资产视图**：面向专业负责人、教务部门、产业研究人员和管理人员，提供课程库、标准岗位、岗位任务、岗位技能、企业/地区/行业分布及数据谱系等业务视图，支持专业建设方案、课程优化、人才需求调研和供需匹配分析。

### 1.3 建设原则

- **证据优先**：课程、任务、技能和分类结论均能回溯到来源文档、岗位原文或原始业务信息。
- **事实与推断分层**：原始材料、抽取事实、归纳结果和人工结论分层管理，避免推断结果覆盖原始依据。
- **单岗位抽取、全量归一**：六要素按单个岗位需求抽取，岗位合并和标准岗位统计在完整数据集快照范围内执行。
- **规则和版本可追溯**：课程标准、岗位归一、词典和分类口径均保留版本与变更依据，支持结果复核和历史比较。
- **业务视图面向使用者**：以专业、课程、岗位、任务和技能等业务对象组织信息，避免业务人员面对底层数据结构。

## 二、项目解决方案

### 2.1 总体业务方案

项目以统一的数据资产底座承载三类业务对象，形成“标准课程基线—市场岗位需求—专业建设应用”的业务闭环：

```text
专业教学标准
  → 标准课程整理与证据核验
  → 标准课程库
  → 课程体系对标与专业建设应用

市场岗位需求
  → 原始岗位留存与观测整理
  → 岗位内容清洗和同一需求识别
  → 六要素任务抽取
  → 岗位任务画像、岗位核心技能画像
  → 标准岗位归一与岗位需求统计

标准课程库 + 标准岗位库 + 业务分析结果
  → 课程、岗位、任务、技能和市场需求资产视图
  → 专业建设、课程优化和人才需求调研
```

### 2.2 标准课程库建设方案

1. **建立专业教学标准基线**：以现行有效的专业教学标准为依据，系统整理专业定位、培养目标、职业面向、课程结构、课程类型、典型工作任务和主要教学内容，形成完整的专业课程基线。
2. **形成标准课程单元**：将每门课程作为可独立引用的标准课程单元，明确课程所属专业、课程性质、典型工作任务、教学内容与要求，并区分公共基础、专业基础、专业核心和拓展课程等类型。
3. **建立课程能力标签**：围绕课程实际承担的培养职责，归纳知识、技能、工具、方法和职业素养等标签，形成课程与工作任务、岗位能力之间的可解释关联，避免仅按课程名称进行比较。
4. **实行标准版本管理**：每份教学标准形成独立版本，课程调整、课程新增和课程退出均保留变化记录。标准课程库的正式生效以完整标准审核为前提，确保专业负责人看到的是经过确认的完整课程体系。
5. **保留来源依据**：课程名称、工作任务和教学内容均保留对应的原文位置和来源说明，支持业务人员从课程结论回看标准条文，满足复核、修订和教学评审需要。

### 2.3 市场岗位归一与岗位画像建设方案

1. **统一岗位数据接入口径**：岗位抓取服务提供的标题、薪资、地点、企业属性、技能标签以及职责、任职要求和加分项等信息统一进入岗位分析范围；完整职位描述作为核验和异常情况下的补充依据。
2. **区分同步记录与岗位需求**：一次同步只是数据进入平台的时间窗口，同一企业岗位在多次同步中的变化属于同一岗位需求的历史观测。岗位需求数量、企业数量和趋势分析必须基于经过确认的岗位需求实体，而不能直接按同步次数统计。
3. **完成岗位内容清洗和同一需求识别**：对标题、企业、地区、薪资、技能和文本内容进行规范化，综合来源标识、岗位链接、企业与地区、岗位内容和时间连续性识别同一岗位需求。无法确定的近似岗位保留为待复核关系，不因标题相似而强行合并。
4. **以职责为核心抽取六要素**：从岗位职责中提取动作、对象、工具、工艺或方法、工作场景、成果或质量约束；任职要求用于识别岗位必须具备的能力，加分项用于识别优先但非必需的能力。每项抽取结果均保留岗位原文证据和置信度。
5. **先形成单岗位画像，再进行标准岗位归一**：每个岗位需求独立形成完整的任务画像和核心技能画像，保留任务出现顺序、重复强调、必备/加分等级及其证据。单岗位画像不跨岗位合并；只有在全部岗位画像完成后，才依据任务语义、任务结构、技能要求和场景边界将相近岗位归入标准岗位。
6. **形成标准岗位工作内容和技能要求**：标准岗位归一后，统计不同岗位需求和不同企业对任务、技能和工具的支持情况，分别识别核心任务、补充任务、必备技能和扩展技能，并形成代表性工作内容和技能要求。
7. **开展职业标准核验**：将企业岗位归纳形成的标准岗位与国家职业大典、职业标准和行业技能标准进行对照，明确直接对应、部分对应、相关参考或暂无直接对应等关系，既借助权威标准校准边界，也保留企业岗位市场语义。

### 2.4 业务面数据资产视图建设方案

业务视图以专业人员能够直接理解和使用的对象组织信息，重点建设以下六类视图：

| 业务视图 | 展示重点 | 主要应用 |
| --- | --- | --- |
| 标准课程库视图 | 专业课程体系、课程类型、典型工作任务、教学内容、能力标签和标准版本 | 专业负责人制定课程体系和修订教学内容 |
| 标准岗位库视图 | 标准岗位名称、岗位定义、企业岗位范围、工作内容、核心技能和职业标准对照 | 专业建设、产业调研和岗位群分析 |
| 岗位任务画像视图 | 单个岗位的工作任务、六要素、任务顺序、场景约束和证据说明 | 课程开发、岗位分析和教学任务设计 |
| 岗位核心技能视图 | 必备技能、加分技能、工具方法、技能覆盖范围和代表性证据 | 人才培养目标、技能评价和课程能力校准 |
| 市场需求分析视图 | 岗位需求规模、企业分布、地区行业分布、薪资经验特征和技能趋势 | 招生就业、专业布局和产教融合分析 |
| 数据依据与变化视图 | 数据来源、统计期间、版本变化、审核结论和原文依据 | 业务复核、管理决策和成果审计 |

视图之间建立清晰的业务关联：专业可以查看对应的标准课程和相关标准岗位，标准岗位可以查看核心工作任务和技能要求，课程可以反查其对应的工作任务与岗位能力。所有统计结果明确数据期间、统计口径和有效范围；所有关键结论提供来源依据，支持从汇总结果下钻到岗位或标准文档。

## 三、实施计划与预期成果

### 3.1 分阶段实施

**第一阶段：课程库基础能力。** 完成专业教学标准接入、课程结构抽取、证据绑定、课程库状态和标准课程业务视图，形成首批专业标准课程基线。

**第二阶段：岗位归一与画像能力。** 完成市场岗位数据接入、原始留存、完整数据集整理、清洗去重、岗位身份识别、六要素任务抽取、任务/技能画像和标准岗位候选，形成可回溯的岗位标准库。

**第三阶段：业务视图与应用服务。** 完成课程—岗位任务—核心技能关联视图和市场需求分析，形成面向专业建设方案、课程优化和人才需求调研的业务查询与应用服务。

### 3.2 主要交付物

- 版本化标准课程库及课程证据链；
- 原始岗位数据、岗位需求实体、观测历史和完整快照管理能力；
- 标准岗位库、岗位任务画像、岗位核心技能画像及岗位词典；
- 课程、岗位、任务、技能和市场需求业务视图；
- 岗位归一、课程整理、词典治理和分类口径说明；
- 数据依据、版本变化、审核流程和成果复核材料。

### 3.3 预期成效与验收方向

1. **课程标准化**：课程记录能够回溯到标准文档的章节或表格证据，课程库支持版本差异、课程类型和能力标签检索，标准更新能够清晰反映课程变化。
2. **岗位可分析**：岗位需求量与历史观测严格区分；任务和技能结论均可回溯到岗位原文；标准岗位归一能够解释相似依据、边界条件和人工结论。
3. **业务可使用**：业务人员可以按专业、岗位、地区、行业和时间查看课程与市场需求，获得标准岗位工作内容和核心技能，并定位到原始证据。
4. **成果可持续**：课程标准、岗位口径、词典和分析结果可持续更新；低置信度和冲突结果进入复核；正式发布、人工修订和统计口径均保留审核记录。

项目完成后，将形成“专业教学标准定义课程基线、市场岗位数据反映产业需求、业务资产视图支撑分析决策”的统一数据闭环，为专业建设、课程更新、人才培养方案优化和产教融合分析提供可靠的数据基础。
