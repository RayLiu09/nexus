## 分析与改动

此前开启联网查询耗时 150.83 秒，但没有保留阶段计时，不能事后断言其慢在联网。
对未优化代码重新执行同一问题，得到 56.54 秒，首段回答 44.931 秒。
按当时 SSE 墙钟时间粗估，三次规划分别约 6.9、11.3、11.3 秒，回答合成约
24.5 秒，联网 HTTP 约 3.5 秒，其余多数 HTTP 不足 0.5 秒。
这些阶段近似数不能精确加总为总耗时；后续改用单调时钟计时。
该样本表明模型规划与合成是主要开销，优先消除额外模型轮次和重复输入。

- 普通文档问题从已返回且标题与问题有词重合的 normalized ref 中排序读取最多
  3 份正文，省去单独证据规划。该排序只决定读取优先级，不是相关性置信度。
  图谱、目录、章节、上下文等问题保留专门模型规划，其他资源也不强制走文档路径。
  正文均不可用时，在剩余 16 次预算内回退一次实际返回目录/章节。
- 回答上下文将工具状态、查询口径、完整聚合统计与来源证据分开，避免同一正文
  在 TOOL_RESULTS 和 CITATIONS 中重复传入；保留业务字段、日期、证据级别及全部引用编号。
  普通正文最多 5,000 字符，异常大上下文仍受限并标注截断；不减少要求的网页数量或回答 token 上限。
- 现有最终查询审计增加 `performance`：单调时钟阶段耗时、首段/总耗时、HTTP 次数、
  规划请求数/工具 Schema 大小和合成输入字符数。只记录技术标签和数值，不记录问题、正文或凭证。
- 本轮未引入 HTTP 并发、新 API、依赖或基础设施，未修改模型路由或覆盖 active Prompt。

## 实际复测与局限

相同问题：`请查找重庆市2026年低空经济领域相关政策，以及产业链分布`。
使用本机已存在业务专家身份、相同模型配置和内部 SSE 入口，开启联网；
`INGEST_SEARCH_RESULTS=false`，Worker/爬虫调度/同步运行关闭。

| 样本 | 总耗时（客户端） | 首段回答（客户端） | 模型规划次数 | 最终实际引用 |
| --- | ---: | ---: | ---: | ---: |
| 历史运行 | 150.83 秒 | 未保留 | 未保留阶段计时 | 8 |
| 优化前重新测量 | 56.54 秒 | 44.931 秒 | 3 | 9 |
| 优化后第 1 次 | 44.83 秒 | 31.806 秒 | 2 | 10 |
| 优化后第 2 次 | 58.61 秒 | 48.242 秒 | 2 | 13 |

优化后两个样本内部总耗时约 43.97/58.59 秒，客户端与服务端计时起止点不同。
规划合计约 17.93/25.96 秒，合成约 20.92/25.53 秒，联网 HTTP 约 3.60/3.75 秒。
HTTP 次数 12/13，均通过直接正文路径读取 3 份正文，没有目录 404、失败动作或最终 warnings。
两次搜索均实际登记 10 条网页候选，搜索入库关闭；最终引用编号集合与回答内有效编号集合一致。
保留了平台正文和网页来源，未以元数据代替取得的正文。

第 1 次较新基线更快，第 2 次仍略慢，说明模型规划内容、检索返回和供应商响应存在波动。
这些少量样本只支持“减少普通文档问题的一次规划，消除重复上下文”，不足以证明稳定的
端到端百分比收益，不能把 151 秒到 45 秒作为受控性能提升或承诺固定完成时限。
本次也不是检索质量完整评测：引用存在不保证每个结论都受来源支持，地域/日期约束和
事实蕴含仍需后续样本评测。下一步应结合新增计时积累同类查询分位数，再判断规划收敛、
工具 Schema 分层和有限并发的收益，避免仅凭个别慢样本调整模型或缩减证据。

## 引用展示修复

卡片父级 `.sourceCard > span` 的 `display:block` 覆盖原 `line-clamp-2`，
导致截断失效。改用更明确的 CSS Module 正文选择器，限制 6 行、1.5 倍行高，
最大高度 9em；来源网格顶部对齐，短卡片按实际内容高度显示。
保留全部来源内容供抽屉预览，截断仅影响卡片展示。

移除抽屉“查看平台资产”链接，清理不可用入口的提示文字；保留安全 HTTP(S)
“打开网络资源”外链及新标签页保护。移除输入框上方“本页保留记录 · 每次查询独立执行”，
查询历史行为保持现有实现。

后续岗位引用调整：`query_market_jobs` / `get_market_job` 的引用抽屉即使带来源 URL，
也不显示“打开网络资源”；联网搜索的网页引用仍保留此链接。定向 ChatMessage
回归 8 passed（包含两个岗位入口和网页外链正例），定向 ESLint 与差异检查通过。

浏览器覆盖 1920px 和 390px：长正文计算样式 clamp=6，高度不超过六行，真实内容
高度大于展示高度，卡片总高度小于 200px，短卡片明显更矮；抽屉仍展示完整取得的网页正文，
平台引用仍懒加载资产 Markdown；移除资产入口、保留外链、页面无横向溢出。
