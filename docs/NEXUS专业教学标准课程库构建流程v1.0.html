专业教学标准课程总库
建设目的、业务价值与总流程

将国家/行业专业教学标准原文，一次投影为版本化、可追溯的"专业标准 + 课程"总库，作为后续课程体系自动生成、检索问答与人才培养方案校核的默认底数。

建设目的

过去教研人员从 PDF 版专业教学标准手工誊录课程与学时， 效率低、易失真、无法回溯。课程总库要做的是把国家/行业标准中 专业基础、专业核心、专业拓展三类课程的事实与推导数据， 以标准原文为唯一依据，一次性投影为 结构化、可查询、可复用的默认底数；不改写标准， 也不替代学校真实开课决策。

业务价值

01
标准原文一次抽取，全平台复用 课程体系生成、语义检索、QA、培养方案校核共享同一份可信底数，避免重复誊抄与偏移。
02
证据可回溯，判定可复现 每条课程绑定原文章节 / 页码 / 表行；每次推导保留输入/输出指纹，业务专家和审计随时可追问。
03
建议课时与标签，作为学校默认值 按复杂度带给出"建议"总/实践学时与四类标签，学校可直接采用或按校情微调，不冒充"标准规定"。
04
版本可替代，历史不丢 新版本发布后旧标准转为 superseded 状态，仍可查询与追溯，为审核与合规提供完整的时间线。

总流程

标准入库 系统 · 自动

专业教学标准 PDF/HTML 完成解析与标准化，进入平台的治理后规范化文档。

标准事实抽取 系统 · 确定性

按章节语义识别"职业面向、培养层次、课程结构、学时规则"等标准级字段；不猜测，无法确认留空。

课程事实抽取 系统 · 确定性

拆分三类课程；核心课程按表格逐行落地；跨页续表按序号合并；同名课程仅保留一条记录、累积证据。

批量推导 AI · 一标一次

一个专业标准发起一次 LLM 调用，产出培养目标摘要与全部课程的标签/复杂度；建议课时与匹配字段由规则本地生成。

进入 review 状态 系统 · 待审

整个专业标准及其全部课程一起进入待审队列，AI 输出永远不会直接上线。

业务专家整体审核 业务专家

以"一个标准 + 全部课程"为审核单元；不逐课程标注置信度，逐条勾选或整体驳回重跑。

推进为 active 上线 业务专家 · 命令

整批审核通过后统一推进为 active；相关课程库随之可检索、可用于课程体系生成。

生命周期 review ▶ active ▶ superseded 新构建 · 待审 → 审核通过 · 上线 → 有新版覆盖 · 历史保留可追溯

2 Business Rules

课程总库构建业务规则

六组业务规则约束整个抽取与推导过程，共同保障"课程库始终等价于标准原文的可复用投影"，任何偏离都必须在业务专家整体审核处显性化。

Source · reference-1.md § 1–7
Rule Sets · 6
业务专家单元 · 一个标准 + 全部课程
① 课程边界与来源 § 3.5
  • 只抽取专业基础 / 专业核心 / 专业拓展三类章节明确列出的课程。
  • 公共基础课与实践性教学环节不进入课程库。
  • 禁止用"实训 / 实习 / 毕业设计 / 项目"等课程名关键词建黑名单过滤 —— 只要标准把它列入三类专业课程，就按原文保留。
  • 课程名严格取自"课程涉及的主要领域"列，不改写、不推断替代名称。
三类课程 = 唯一入口
② 标准事实抽取 § 1.1
  • 培养层次由"入学基本要求"文本语义推断：普通高中/中职毕业 → 高等职业专科；初中毕业 → 中等职业专科。
  • 专业大类 / 专业类由"职业面向"表的括号内容拆出 code 与 name，名称去掉括号代码与噪音。
  • 课程结构由"课程设置"章节总结（专业基础/核心/拓展三部分）。
  • 无法从原文确认的字段一律留空，不允许猜测。
留空 > 猜测
③ 课程唯一性与命名 § 3.4 · 4.1
  • 同一父标准 + 同一课程类型 + 同一课程名 只有一条记录；多来源命中同一逻辑课程只累积证据。
  • 核心课表跨页续表按"序号 + 课程名"合并，不重复保存续表标题。
  • 课程 ID 规则：<前缀><专业代码>-<B|C|E><NN>（B/C/E = 基础/核心/拓展）。
  • 顺序调整时优先按"父标准 + 类型 + 课程名"保留旧 ID，避免下游断链。
一门课 = 一条记录 + N 条证据
④ 标签与匹配字段 § 4.2 · 5
  • 四类标签：知识 / 技能 / 工具 / 素养。均不保留完整句子，不保留"掌握 / 了解"等动词。
  • 工具标签只记录真实工具（软件/系统/平台/设备）；无稳定工具要求填 无特定工具要求，禁止硬填"计算机"。
  • 素养标签须体现课程差异，禁止所有课程机械填写同一套。
  • 匹配字段 match_keywords / match_text 由固定顺序与模板本地渲染；空字段整段跳过，不写建议课时或页码。
检索面向语义，不面向原文噪声
⑤ 建议课时与实践比例 § 6
  • 课时统一标注为"建议课时"，禁止写成"标准规定课时"。
  • 总学时优先取 16 / 24 / 32 / 48 / 64 / 80 / 96 / 112；核心课与职业本科课程优先 16 的整数倍。
  • 按课程复杂度落入学时带；实践比例按课程性质取 20% – 75% 区间。
  • 汇总校验：为公共课、选修、实习、毕业设计预留空间；总量超出则降低单门建议值，不挤压实习。
建议 · 非标准规定
⑥ 生命周期与整体审核 § 1.2 · 7
  • 新构建的标准与其全部课程统一进入 review；AI 输出永远不会直接成为 active。
  • 业务专家审核单元 = 一个专业标准 + 其全部课程库记录，逐条勾选或整体驳回重跑。
  • 整批通过后统一推进为 active；新版本发布时旧版转 superseded，历史证据保留。
  • 课程库不设逐课程 confidence_level / need_confirm / review_status 字段。
整标审核 · AI 不越权

3 Extraction Rules & Reliability

事实抽取· 标准事实 & 课程事实的处理规则与可靠性保证

两段抽取均为纯确定性算法（章节语义 + 表格解析 + 正则规则），不调用 LLM、不改动源文本；每条落库记录都携带证据锚点，任何缺失以显式质量标记呈现给业务专家。

Standard Facts · Slice 1

标准事实抽取

专业教学标准 → 一条 review 态的标准库主记录 + 职业面向 / 学时规则子表

处理规则 · Extraction Rules

  • 标题 + 编号联合识别章节：按"职业面向 / 培养目标 / 培养规格 / 课程设置 / 学时安排"等章节名与编号识别，不依赖固定页码。
  • 4 类职业面向自动归位：applied_industry / occupation_type / primary_position / certificate_type；"章节别名"与"表列头别名"两条通路各自命中，互不遗漏。
  • 专业大类 / 专业类 code-name 分离：括号内数字写入 code，名称字段仅保留中文名，去除"（代码）"、括号代码与表格分隔符噪音。
  • 培养层次语义推断：由"入学基本要求"文本判断（普高/中职毕业 → 高等职业专科；初中毕业 → 中等职业专科）。
  • 6 类学时规则正则：total_hours · practice_ratio · public_foundation_ratio · professional_course_ratio · elective_ratio · internship_months；抽取 comparator ∈ { ≥ ≤ = range } 与 numeric_value。
  • 无法确认字段留空：不猜测；缺失以 quality_flags 标记（major_identity_missing / occupation_orientation_missing / course_structure_missing）。

可靠性保证 · Reliability

  • Idempotency hash_digest = sha256(validated_facts) · UNIQUE(normalized_ref_id) 保证同源重跑等价、不产生第二条投影。
  • Traceability 每条 occupation / rule 均记录 evidence_block_ids + locator{section, table_row, column}，可精准回到原文行。
  • Transparency quality_flags 显式标记缺失，业务专家一眼看到"什么没抽到"，不被静默吞掉。
  • Stability 重建仅覆盖 occupation / rule 子表；父记录 status / summary 不被确定性重跑重置。
02
Course Facts · Slice 2

课程事实抽取

标准库 → 专业基础 / 核心 / 拓展 三类课程记录（18 字段业务契约）

处理规则 · Extraction Rules

  • 三类章节别名匹配：foundation / core / extension；"专业选修课程"并入 extension；命中章节以外的内容不进课程库。
  • 基础 / 拓展课：段落按 、 , ; 拆分，删除"等领域的内容 / 等领域的课程"尾缀；保留原文课程名，不改写、不合并。
  • 核心课表头指纹：定位"课程涉及的主要领域 / 典型工作任务描述 / 主要教学内容与要求"三列；课程名严格取自"课程涉及的主要领域"列。
  • 跨页续表按 (table_id, 行序号) 合并：首格为空、任务/教学内容非空且序号连续 → 追加到上一条课程，不新增记录；重复表头行直接跳过。
  • 同键仅一条 + 追加证据：UNIQUE(library_id, course_type, standard_course_name)；多来源命中同一课程只累积 evidence_bindings。
  • 课程 ID 分配：VC<major_code>-<B|C|E><NN>；父标准无 major_code 时退化为 S<hash8>，不伪装成专业代码。

可靠性保证 · Reliability

  • Uniqueness UNIQUE(library_id, course_type, standard_course_name) + UNIQUE(library_id, course_id) 双约束，物理防重复。
  • Evidence Accretion 同键多次命中：追加章节 / 页码 / 表行 / block_id，从不静默丢弃后续来源。
  • Change Isolation source_hash 变化即清空派生字段（tags / hours / match_*），保证 Slice 3 重跑不会残留旧推导。
  • Diagnostics core_course_table_missing / core_course_row_incomplete 落入 quality_flags，异常表 / 异常行数直接可见。
