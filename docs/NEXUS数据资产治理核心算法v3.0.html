状态机

1. 分类算法

  • 领域 Schema 形成 candidate mask，阻止无结构证据的错分类。
  • HanLP NER + 词典统计专业、课程、岗位、政策、指标证据密度。
  • LiteLLM 在 mask 内输出 classification/confidence/reasons/evidence_refs。
Pclass = calibrate(LLM_confidence, schema_evidence, entity_evidence, conflict_flags)

2. 分级算法

  • 导入源以 L1/L2 为默认先验。
  • 规则 + HanLP span + LiteLLM 检测个人信息、凭据、商业秘密和精确个人定位。
  • 高敏命中必须有 exact evidence span；规则与 AI 冲突取更严等级并人审。
  • L3/L4 要求显式审批、脱敏与审计。

3. 打标算法

候选 = 分类可用标签维度 ∩ (词典命中 + HanLP 术语 + LLM 语义候选)
接纳 = registry_valid AND applicable_to(classification) AND evidence_span_exists AND confidence ≥ threshold

高置信标签自动提交并审计；低置信、同义冲突、新术语进人审队列。

约束边界：metadata_enrich 标签目标是 normalized asset，不是 chunk；AI 证据必须属于同一 normalized ref。

内在质量分

I = .20*provenance_coverage + .15*sentence_boundary_integrity + .15*semantic_cohesion + .10*self_containment + .10*(1-noise_ratio) + .10*size_fitness + .10*structure_atomicity + .10*index_readiness

外在检索效果分

R = .25*Recall@5 + .15*nDCG@10 + .20*answer_context_recall + .20*citation_precision + .10*section_context_hit_rate + .10*(1-no_answer_false_positive_rate)

指标含义

  • semantic cohesion：块内句向量与 centroid 的平均 cosine。
  • self containment：无悬空指代、标题缺失、实体/谓词不全的句比例。
  • structure atomicity：表行、QA、步骤、指标口径不被错拆/错并。
约束边界：硬检查 block 的 chunk 不进入公共 QA，生成重建/人审任务；质量报告不直接改变资产状态。记录块使用 source row identity 代替文档 locator。

事实候选契约

subject(type,name) --predicate--> object(type,name) | object_literal + fact_type + qualifiers + confidence + source_chunk_id / evidence_chunk_ids + exact evidence_text

归一与合并

  • 实体：NFKC/空白/编号清理 → HanLP 边界 → 标准码/别名词典 → type+canonical_name。
  • 谓词：同义关系映射受控谓词；未知谓词不直接入库。
  • 量值：保留 raw literal，归一 value/unit/time/region；维度冲突不合并。
  • 事实键：subject/predicate/object/literal/semantic qualifiers；取最大置信度并合并 evidence。

事实显著性分

S = .25 + .24*core - .18*low_value + .18*strong_predicate - .16*weak_predicate + .08*entity_object + min(.16,literal_len/500) + .18*multi_chunk_evidence + .12*context_link + .08*valid_context_role + .18*(confidence-.70) - .18*generic_entity
拒绝条件
S<0.45；弱 MENTIONS；低显著通用实体；同源块单证据候选 >8。
持久化门禁
confidence≥0.70；exact evidence 存在；evidence chunk 属于同一 normalized ref。
