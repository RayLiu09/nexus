# 职业教育专业教学标准构建课程库领域模型参考规范

## 1. 专业标准清单字段

`teaching_standard_manifiest` 固定字段：

| 字段 | 说明 |
| --- | --- |
| `standard_id` | 标准唯一编号 |
| `major_code` | 专业代码 |
| `major_name` | 专业名称 |
| `education_level` | 培养层次 |
| `major_category_code` | 专业大类代码 |
| `major_category_name` | 专业大类名称 |
| `major_class_code` | 专业类代码 |
| `major_class_name` | 专业类名称 |
| `basic_study_years` | 基本修业年限 |
| `source_standard` | 标准标题 |
| `total_hours_rule` | 总学时规则原文 |
| `public_course_ratio_rule` | 公共基础课比例规则原文 |
| `practice_ratio_rule` | 实践学时比例规则原文 |
| `elective_ratio_rule` | 选修课程比例规则原文 |
| `internship_rule` | 实习规则原文 |
| `status` | active/review/superseded |
| `notes` | 备注 |

无法从 PDF 或页面确认的信息留空，不得猜测。

## 2. 文档结构章节识别

专业教学标准通常包含：

```text
1 概述
2 专业名称（专业代码）
3 入学基本要求
4 基本修业年限
5 职业面向
6 培养目标
7 培养规格
8 课程设置及学时安排
8.1 课程设置
8.1.1 公共基础课程
8.1.2 专业课程
（1）专业基础课程
（2）专业核心课程
（3）专业拓展课程
8.1.3 实践性教学环节
8.1.4 相关要求
8.2 学时安排
```

实际标准可能略有格式差异，应使用标题语义和编号联合识别，不依赖固定页码。

## 3. 课程提取规则

### 3.1 专业基础课程

标准常见表述：

```text
主要包括：A、B、C、D 等领域的内容。
```

或中职：

```text
一般设置4门。包括：A、B、C、D等领域的课程。
```

处理：

1. 按中文顿号、逗号、分号拆分；
2. 删除“等领域的内容”“等领域的课程”；
3. 保留标准原课程名称；
4. 不自行改名；
5. `typical_work_task_description` 留空；
6. `teaching_content_requirement` 留空；
7. 标签按课程领域保守归纳；
8. `confidence_level=中`；
9. `need_confirm=是`。

### 3.2 专业核心课程

专业核心课程表常见列：

```text
序号
课程涉及的主要领域
典型工作任务描述
主要教学内容与要求
```

每行生成一门标准课程。

必须保留：

- 课程名称；
- 典型工作任务描述全文；
- 工作内容；
- 工具原文；
- 主要教学内容与要求全文；
- 来源页码。

跨页续表处理：

1. 以序号和课程名称为主键；
2. 页末未结束内容与下一页同序号续表合并；
3. 不重复保存续表标题；
4. 合并后进行页面图像核验。

### 3.3 专业拓展课程

处理方式与专业基础课程相同。

专业拓展课程是候选池，不代表学校全部开设。

### 3.4 重复课程

同一 文档 中若课程列表重复出现：

```text
主键 = major_code + education_level + course_type + standard_course_name
```

同一主键只保留一条，在 `review_status` 或异常日志中说明重复。

不同课程类型出现同名课程时保留两条，不自动合并，因为课程角色不同。

### 3.5 不入库内容

以下不自动作为课程：

- 公共基础课程；
- 实训室名称；
- 实训项目；
- 单项技能实训；
- 综合能力实训；
- 生产性实训；
- 认识实习；
- 岗位实习；
- 毕业设计；
- 社会实践活动；
- 专题讲座。

除非标准在专业课程列表中明确将其列为课程。

| `major_name` | 专业名称 |
| `education_level` | 培养层次 |
| `course_type` | 专业基础课程/专业核心课程/专业拓展课程 |
| `suggested_total_hours` | 建议总学时 |
| `suggested_practice_hours` | 建议实践学时，包含在总学时中 |

| `hours_setting_basis` | 建议课时设置依据 |

| `literacy_tags` | 职业素养标签 |

### 4.1. 课程 ID 规则

```text
<前缀><专业代码>-<课程类型码><两位序号>
```

课程类型码：

| 课程类型 | 代码 |
| --- | --- |
| 专业基础课程 | B |
| 专业核心课程 | C |
| 专业拓展课程 | E |

示例：

```text
VC530701-B01
VC530701-C01
VC530701-E01
```

序号按专业教学标准中出现顺序生成。

课程顺序调整时，应尽量保留既有 ID；增量更新优先通过专业代码、类型和课程名称映射旧 ID。

---

### 4.2. 标签提取规则

#### 4.2.1 知识标签 `knowledge_tags`

回答：

```text
学生需要掌握什么知识、规则、原理、模型和方法？
```

提取动词：

```text
掌握、理解、熟悉、了解
```

标签示例：

```text
平台规则、用户画像、SEO、数据分析指标体系、供应商管理、交互设计
```

不得保留完整句子，不保留“掌握”“了解”等动词。

#### 4.2.2 技能标签 `skill_tags`

回答：

```text
学生能够完成什么工作动作或技术任务？
```

提取动词：

```text
制定、分析、采集、处理、设计、制作、实施、优化、管理、调试、评估
```

标签示例：

```text
商品选品、运营目标制定、数据可视化、广告投放、原型设计、机器人调试
```

专业核心课程应尽量覆盖原文全部关键动作。

#### 4.2.3 工具标签 `tool_tags`

只记录真实工具：

```text
软件、系统、平台、设备、仪器、数据工具、管理工具
```

示例：

```text
ERP系统、CRM系统、数据分析工具、图形图像处理软件、3D扫描仪
```

无稳定工具要求时填写：

```text
无特定工具要求
```

不得为了非空强行填写“计算机”“办公软件”，除非标准明确或课程确有稳定使用场景。

#### 4.2.4 职业素养标签 `literacy_tags`

根据专业培养规格、课程性质和任务场景归纳。

常见标签：

```text
数据意识、用户意识、服务意识、合规意识、风险意识、质量意识、
成本意识、创新意识、团队协作、国际视野、审美意识、版权意识
```

职业素养标签应体现课程差异，禁止所有课程机械填写相同标签。

#### 4.2.5 标签为空规则

| 字段 | 空值处理 |
| --- | --- |
| `knowledge_tags` | 原则上不允许为空 |
| `skill_tags` | 原则上不允许为空 |
| `tool_tags` | 无工具时填“无特定工具要求” |
| `literacy_tags` | 原则上不允许为空 |

基础课和拓展课标签属于系统归纳，必须 `need_confirm=是`。

## 5. 匹配字段生成

### 5.1 `match_keywords`

生成顺序：

```text
standard_course_name
+ 典型工作任务名称
+ knowledge_tags
+ skill_tags
+ 有效 tool_tags
+ literacy_tags
```

处理：

1. 拆分标签；
2. 去空；
3. 去重；
4. 保持首次出现顺序；
5. 以中文顿号连接；
6. “无特定工具要求”不进入结果；
7. 不加入专业代码、来源页码和建议课时。

伪代码：

```python
keywords = ordered_unique(
    [course_name]
    + task_names
    + knowledge_tags
    + skill_tags
    + valid_tool_tags
    + literacy_tags
)
match_keywords = "、".join(keywords)
```

### 5.2 `match_text`

固定模板：

```text
课程名称：{standard_course_name}。
适用专业：{major_name}（{major_code}）。
学历层次：{education_level}。
课程类型：{course_type}。
典型工作任务及工作内容：{typical_work_task_description}。
主要教学内容与要求：{teaching_content_requirement}。
知识标签：{knowledge_tags}。
技能标签：{skill_tags}。
工具标签：{tool_tags}。
职业素养标签：{literacy_tags}。
```

规则：

- 空字段整段跳过；
- “无特定工具要求”整段跳过；
- 不加入建议课时，避免影响课程语义匹配；
- 源字段更新后重新生成；
- 不由教研人员人工改写。

## 6. 建议课时生成

### 6.1 总原则

专业教学标准通常只规定人才培养方案总学时和比例，不逐门规定课程学时。

课程库中的课时必须标注为：

```text
建议课时
```

不得写成：

```text
标准规定课时
教育部要求本课程学时
```

建议课时用途：

```text
课程库默认值
→ 自动生成课程体系
→ 学校调整
→ 人才培养方案总量校验
```

### 6.2 学时基本单位

建议总学时优先使用：

```text
16、24、32、48、64、80、96、112
```

核心课程和职业本科课程优先采用 16 学时的整数倍。

建议实践学时通常使用 8 学时的整数倍，且：

```text
suggested_practice_hours <= suggested_total_hours
```

### 6.3 课程复杂度权重

#### 专业基础课程

| 类型 | 建议总学时 |
| --- | --- |
| 理论认知型 | 24—48 |
| 理论+案例型 | 32—64 |
| 工具/数据/设计基础型 | 48—96 |

#### 专业核心课程

| 类型 | 建议总学时 |
| --- | --- |
| 单一执行任务 | 48—64 |
| 多任务综合执行 | 64—80 |
| 完整业务流程/综合项目 | 80—96 |
| 复杂管理、设计、数据建模或研发 | 96—112 |

#### 专业拓展课程

| 类型 | 建议总学时 |
| --- | --- |
| 素养/认知拓展 | 16—32 |
| 标准应用拓展 | 32—48 |
| 技术/工具/项目拓展 | 48—64 |
| 职业本科高级技术拓展 | 64—96 |

### 6.4 实践比例

| 课程性质 | 建议实践比例 |
| --- | --- |
| 理论基础课 | 20%—40% |
| 案例/方法基础课 | 40%—55% |
| 工具/数据/设计基础课 | 55%—70% |
| 专业核心执行课 | 55%—70% |
| 综合项目/设计/研发核心课 | 65%—75% |
| 实践型拓展课 | 60%—75% |

### 6.5 培养层次校验

#### 中等职业教育

优先读取标准第 8.2 节。常见规则：

```text
三年总学时不少于3000
公共基础课程一般约占1/3
专业课程一般约占2/3
实践性教学原则上不少于50%
选修课程不少于10%
实习累计不超过6个月
```

中职课程强调基础操作、岗位执行和规范训练，不宜将单门课程课时设置得过高。

#### 高等职业教育专科

常见规则：

```text
总学时不少于2500
公共基础课一般不少于25%
实践性教学原则上不少于50%
选修课程不少于10%
实习累计一般为6个月
```

高职专科课程强调完整工作任务、综合实践和岗位应用。

#### 高等职业教育本科

常见规则：

```text
总学时不少于3200
公共基础课一般不少于25%
实践性教学原则上不少于60%
选修课程不少于10%
实习累计一般不少于6个月
```

职业本科课程应体现：

- 复杂业务问题分析；
- 技术方案与管理方案制定；
- 数据建模与技术应用；
- 产品、服务与流程设计；
- 技术研发、改进和成果转化；
- 综合项目实施和评价。

### 6.6 汇总校验

基础课+核心课建议总学时只是专业课程主体，不应直接填满人才培养方案。

必须给以下内容预留空间：

```text
公共基础课程
专业拓展课程选修
综合实训
岗位实习
毕业设计
创新创业和特色课程
```

若基础课+核心课建议总学时过高，应降低单门建议值，而不是挤压实习和选修空间。

## 7. 可信度规则

| 数据类型 | 可信度 |
| --- | --- |
| 核心课程名称、任务原文、教学要求原文 | 高 |
| 专业基础/拓展课程名称 | 高 |
| 核心课程标签 | 高或中 |
| 基础/拓展课程标签 | 中 |
| 建议课时 | 中 |
| 无法从原文确认的工具或素养 | 中或低 |

`need_confirm`：

- 标准明确原文也建议设为“是”，因为课程库仍需学校用于具体方案时复核；
- 若系统用于纯标准库审核，可将核心课程原文记录设为“否”，标签和课时仍为“是”。

## 8. 质量检查清单

### 8.1 来源质量

- [ ] 所有正式 PDF 为教育部官方域名；
- [ ] URL 位于目标专题路径；
- [ ] PDF 名称、代码、层次和任务范围一致；
- [ ] 每个 PDF 已记录 SHA-256；
- [ ] 下载失败已进入异常日志。

### 8.2 课程完整性

- [ ] 专业基础课程列表全部提取；
- [ ] 专业核心课程表全部提取；
- [ ] 专业拓展课程列表全部提取；
- [ ] 核心课程跨页续表已合并；
- [ ] 核心课程数量与表格序号一致；
- [ ] 标准重复课程已去重并记录；
- [ ] 公共基础课和实习环节未误入库。

### 8.3 字段完整性

- [ ] 所有记录有课程 ID；
- [ ] 所有记录有标准课程名称；
- [ ] 所有记录有专业名称、代码和层次；
- [ ] 所有记录有课程类型；
- [ ] 核心课程任务原文和教学要求非空；
- [ ] 知识、技能、素养标签非空；
- [ ] 无工具课程填写“无特定工具要求”；
- [ ] 来源章节和页码可追溯。

### 8.4 匹配字段

- [ ] `match_keywords` 非空；
- [ ] 无重复关键词；
- [ ] 不含“无特定工具要求”；
- [ ] `match_text` 非空；
- [ ] 空字段未写成“无明确标签”；
- [ ] 建议课时未写入语义文本。

### 8.5 课时质量

- [ ] 建议总学时合理；
- [ ] 建议实践学时不大于总学时；
- [ ] 课时区间包含建议总学时；
- [ ] 建议课时不冒充标准规定；
- [ ] 汇总后为公共课、选修、实习和毕业设计保留空间；
